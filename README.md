# Gemma 4 Emotion Fine-Tuning
 
Fine-tune **Gemma 4 E4B-it** on the [`dair-ai/emotion`](https://huggingface.co/datasets/dair-ai/emotion) dataset using LoRA and 4-bit quantization. Runs on a single GPU, including a free Colab T4.
 
**Task:** Classify text into one of 6 emotions: `sadness` `joy` `love` `anger` `fear` `surprise`
